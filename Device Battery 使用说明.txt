========================================
  Device Battery —— 托盘电量显示器  使用说明
========================================

【它是干什么的】

  常驻系统托盘，显示外接无线设备（蓝牙键鼠耳机、罗技 2.4G 设备等）的剩余电量。
  图标上直接显示百分比数字，鼠标悬停可看全部设备，右键看明细。
  软件名就叫 Device Battery（中间有空格），exe、开始菜单、任务管理器里的显示名
  都统一用这个名字。


【怎么用】

  1. 双击「Device Battery.exe」即可启动。桌面和开始菜单里的图标名也是
     「Device Battery」。
     第一次启动会自动在桌面和开始菜单补一张「Device Battery」快捷方式
     （桌面被重定向到别的盘也能找对位置）；自己删掉了就不会再自动重建，
     想重做就右键托盘图标 →「创建快捷方式（桌面 + 开始菜单）」。
  2. 图标默认在托盘「^」溢出区里 —— 第一次用需要把它拖到常显区：
     点开 ^ → 按住「Device Battery」图标 → 拖到常显区松手即可。
  3. 左键单击图标 = 弹出竖列设备面板（再点一次收起，点面板外面也会收）。
     · 面板贴在托盘图标正下方、左边缘与图标左边缘对齐；任务栏在屏幕底部时
       自动翻到图标上方。不跟鼠标指针跑。
     · 程序已经在跑的时候，再双击一次「Device Battery.exe」＝把面板叫出来，
       不会重复开一份（只会有一个托盘图标）。
  4. 右键单击图标 = 弹出设置菜单（菜单底部会显示当前版本号）。

  竖列面板长这样，一行一个设备：

     Device Battery                    刚刚更新
     ──────────────────────────────────────
     ● 无线鼠标 M720  2.4G  [███░░░]  ≈57%
     ● 蓝牙键盘 K380  蓝牙  [██░░░░]   45%
     ● 降噪耳机 WH-1000XM4  [░░░░░░]   10%
     ● 游戏手柄 Pro         [██████]  ≈95%

     左边圆点是状态色，中间是电池图形（按电量填充），右边是百分比。
     设备名后面的小字（2.4G / 蓝牙）是这一行数据来自哪条链路。
     「≈」表示这是按历史掉电速度算出来的估算值。

  面板外观：磨砂玻璃质感 —— 背景抠取屏幕后做高斯模糊，再压一层 50% 的深色，
  圆角 13px。所以背后的画面会柔柔地透出来，但看不清细节。

  觉得太透/太实，改源码 popup.py 顶部这几个常量就行：
     BACKDROP_OPACITY = 0.50   背板不透明度（0.3 更透，0.7 更实）
     BACKDROP_BLUR    = 26.0   模糊半径，越大越糊
     BACKDROP_RADIUS  = 13.0   圆角半径
  改完按 源码\Device Battery 打包说明.txt 重新打包一次。

  右键菜单说明：
     · 前几行是设备清单，带方块电池「■■■□□」和百分比
     · 显示电量面板 —— 等同左键单击
     · 立即刷新      —— 马上重新读一次真实电量
     · 检测间隔      —— 点击可在 15/30/60/120/180 分钟之间循环切换（默认 60 分钟）
     · 开机自启      —— 勾选后开机自动静默运行
     · 创建快捷方式（桌面 + 开始菜单）—— 随时补一张新的桌面图标
     · 版本 v1.0.6   —— 确认自己跑的是哪一版
     · 退出          —— 关闭程序


【设备什么时候出现 / 消失】

  · 每 3 秒做一次轻量探测，只读系统里的缓存属性，不打扰设备
  · 新连上的设备 3 秒内出现在面板
  · 断开的设备 3 秒内从面板收起；记录不删，再连上 3 秒内自动回来
  · 双模键鼠（同一把键盘同时有 2.4G 和蓝牙）只显示一行，标出**当前正在用**
    的那条链路：拨到蓝牙后最多 8 秒换成「蓝牙」，拨回 2.4G 3 秒内换回来


【电量颜色怎么分级】

     低于 25%        红色（该充电了）
     25% ~ 69%       黄色（够用，留意）
     70% 及以上      绿色（充裕）

  托盘图标、面板里的电池、菜单里的文字都按这个规则上色，
  一眼就能看出哪个设备快没电了。托盘图标显示的是「电量最低的那个设备」。


【电量的两个数值是什么】

  · 按「检测间隔」读一次硬件真实电量（默认 60 分钟，这一步是「实测」）
  · 两次实测之间，程序用这台设备历史上的掉电速度做线性推算（这一步是「估算」）
  · 估算值前面带「≈」，面板右上角会写明「X 分钟前更新」

  所以图标数值不是每时每刻都在跳，而是随着时间缓慢下降，
  到下一轮再被真实读数校正一次。这是按你的要求做的省电设计 ——
  不需要一直连设备，也就不会打扰设备休眠。


【能读哪些设备】

  ✔ 蓝牙 / 蓝牙 LE 设备
     键盘、鼠标、耳机、手柄等，只要设备向 Windows 上报了电量。
     例：AULA-F87、Joy-Con、蓝牙耳机。

  ✔ 罗技 2.4G 设备（Unifying / Lightspeed 接收器）
     通过罗技 HID++ 协议直接读，不用装 G HUB 也能读。
     例：G304、G Pro、RO X SUPERLIGHT 等。

  ✔ 狼蛛（AULA）2.4G 设备
     走接收器私有报文，能拿到电量 + 充电状态。例：AULA-F87。

  ✘ 其它品牌的 2.4G 私有协议（七彩虹、雷蛇等）
     Windows 自身不暴露这类电量，只有厂商驱动能读，本工具读不到。
     这类设备不会出现在列表里，不是故障。


【文件位置】

  配置与历史数据：%APPDATA%\Device Battery\
      config.json   设置（检测间隔、自启状态）
      state.json    各设备电量历史（用于算掉电速度）
      app.log       运行日志，出问题时看这个

  从旧版本（v1.0.4 及以前，数据放在 %APPDATA%\DeviceBatteryTray\）升级上来的，
  第一次启动会自动把整个文件夹改名带过来，配置和历史都不会丢。

  删掉整个 Device Battery 文件夹 = 恢复出厂状态（历史掉电记录会丢失，
  重新开始学习；不影响功能）。


【常见问题】

  Q：图标找不到了？
  A：在托盘 ^ 溢出区里。也可能被 Windows 收进了「任务栏角溢出」设置，
     去 设置 → 个性化 → 任务栏 → 其他系统托盘图标 里把它打开。

  Q：双击没反应 / 一闪就没了？
  A：说明已经有一个在运行了（程序是单实例，不会重复开），
     并且第二个会被自动关掉 —— 这是正常的。
     此时已经跑着的那个会把电量面板弹到你面前，
     重复双击只会刷新面板，不会把它关掉。

  Q：双击后只想看面板，不想再看提示框？
  A：不用管提示框了，现在的版本双击就是直接弹面板。
     只有极端情况（面板叫不出来）才会退回提示框。

  Q：某个设备明明连着，但列表里没有？
  A：看上面「能读哪些设备」一节。品牌私有 2.4G 协议读不到。

  Q：数字好像不太准？
  A：整轮那一次是真实读数，中间是估算。用得越久样本越多，估算越准。
     刚装上的头几个小时没有历史，会用 0.5%/小时 的默认速度先顶着。

  Q：会不会很占资源？
  A：常驻内存约 20-30 MB。每 3 秒醒一次做轻量探测（读系统缓存属性，
     实测一轮几十毫秒），整轮硬件读数按「检测间隔」走。
     不向无线设备发轮询请求，不打断设备休眠。

  Q：怎么彻底卸载？
  A：双击程序目录里的「Device Battery 卸载器.bat」，
     它会结束进程、移除开机自启、把程序目录整个移进回收站，
     并单独问一句用户数据留不留。
     手动卸载：右键图标 → 退出；删掉 Device Battery.exe；
     再到 %APPDATA% 删掉 Device Battery 文件夹；
     如果开过自启，退出前记得先在菜单里取消「开机自启」。


【技术备注】

  · 蓝牙电量走 Windows 设备属性 DEVPKEY_Bluetooth_Battery
    （注意这个值是缓存的，经典蓝牙另用 bthprops 的 fConnected 判在线）
  · 罗技电量走 HID++ 2.0，特性 0x1004(UNIFIED_BATTERY)／0x1000(BATTERY_LEVEL_STATUS)
  · AULA 电量走接收器 3554:FA09 的私有报文（UsagePage 0xFF02）
  · 打包为单文件 exe，无需安装 Python 或任何运行库
